## About
Готель Оазис — готель у Чернівцях. Односторінковий лендинг. Hero типографічний (CSS/SVG) — власних фото для нього не було на момент дизайну. Номери показані картками з квадратним фото (1:1) зверху; фото — ілюстративні з Pexels, підібрані за кількістю/типом ліжок, не фото самого готелю (див. Photos). Фото міста й ілюстративні фото зручностей (зарядка, тераса, сніданок) — теж з Pexels.

## Hero concept
Батарея зарядки: вісім клітинок-зручностей заповнюються від темно-зеленого до світлого, остання «заряджається». Концепт виходить із підтвердженої EV-зарядки та парковки.
